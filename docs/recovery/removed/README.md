# کدِ حذف‌شده در فازِ ۲ — بایگانیِ قابلِ بازگردانی

این پوشه **قبل از حذف** یک کپیِ بایت‌به‌بایت از هر فایلی که در فازِ ۲ از درختِ
اپ برداشته شد نگه می‌دارد.

## چرا این پوشه لازم بود

پروتکل §۲۱ می‌گوید «بر اساسِ شهود حذف نکن — اول اثبات کن». اثبات انجام شد، ولی
یک مشکلِ عملیِ جدا هم وجود داشت: **این ریپو هیچ کامیتِ گیتی ندارد**
(`git log` → «your current branch 'main' does not have any commits yet»). یعنی
`git checkout` هیچ‌چیز را برنمی‌گرداند و هر `rm` غیرقابلِ بازگشت است.

راهِ حل: بایگانی پیش از حذف. حذف انجام می‌شود (درختِ اپ تمیز می‌ماند) ولی
بازگردانی همیشه یک `cp` فاصله دارد — بدونِ نیاز به گیت.

## بازگردانی

```sh
cp docs/recovery/removed/RestaurantIntelligenceDashboard.jsx.archived \
   apps/business/src-v2/RestaurantIntelligenceDashboard.jsx
```

### اثباتِ بی‌مصرف‌بودن (هر سه شرط، نه حدس)

۱. **هیچ ارجاعِ اجرایی ندارد.** جست‌وجویِ کلِ ریپو برایِ `src-v2` و
   `RestaurantIntelligenceDashboard` فقط در فایل‌هایِ `.md` (ممیزی/چنج‌لاگ)
   نتیجه می‌دهد — صفر ارجاع در `.html`، `.js`، `.jsx`، `.json`، `.ts`.

۲. **از نظرِ فیزیکی اجراناپذیر است.** `apps/business/` هیچ `package.json`،
   هیچ bundler و هیچ build stepی ندارد (محتوایش فقط `css/`, `js/`,
   `index.html`, `favicon.svg` است). پنل با `<script>`ِ کلاسیک لود می‌شود.
   یک فایلِ JSX بدونِ ترنسپایلر هرگز توسطِ مرورگر اجرا نمی‌شود — حتی اگر
   کسی به آن `<script src>` می‌داد، خطایِ نحوی می‌گرفت.

۳. **خودِ سازنده‌اش هم همین را می‌گوید.** `CHANGELOG-v2.md` خط ۱۴:
   «کنار پنل فعلی قرار گرفت، **هنوز mount نشده**».

### چرا حذف شد و «وصل» نشد

وصل‌کردنش یعنی افزودنِ React + یک build step به اپی که عمداً no-build است —
یعنی دقیقاً «افزودنِ حجمِ زیادی کدِ جدید» که پروتکل §۰ منع کرده. §۲۳ هم
«v2ِ دائمی» را منع می‌کند: یا مهاجرت تمام می‌شود یا شاخه‌ی مرده برداشته
می‌شود. مهاجرتی در جریان نیست.
