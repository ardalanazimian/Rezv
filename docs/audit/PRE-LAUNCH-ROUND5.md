اسکریپت حالتِ «جدول دارد ولی تاریخچه ندارد» را می‌سازد (همان که قبلاً با `P3005`
کانتینر را اصلاً بوت نمی‌کرد)، خودِ `docker-entrypoint.sh` را اجرا می‌کند، و پنج
مرحله را تأیید می‌کند. **اجرای واقعیِ محلی:**

```
✓ پیش‌شرط برقرار: جدول هست، تاریخچه نیست
  ✓ انتظارِ آماده‌شدنِ دیتابیس
  ✓ شاخه‌ی baseline شلیک کرد (گاردِ P3005)
  ✓ migrate deploy اجرا شد
  ✓ apply-sql.sh کامل شد
  ✓ به مرحله‌ی استارتِ سرور رسید
✓ مسیرِ بوتِ تولید سالم است        BOOT_GATE_EXIT=0
```

دو تصمیمِ طراحی که در خودِ اسکریپت ثبت شده‌اند: `exec npm run start` هرگز
برنمی‌گردد پس با `timeout` اجرا و موفقیت از رویِ **مراحلِ طی‌شده** سنجیده
می‌شود؛ و اگر `db push` به‌هر دلیل تاریخچه بسازد گارد صریحاً رد می‌کند، وگرنه
شاخه‌ی baseline آزموده نمی‌شد و گارد بی‌صدا بی‌معنا می‌شد.

این گارد لایه‌ی **ایمیج** را نمی‌سنجد و صریحاً همین را می‌گوید.
